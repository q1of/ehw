## Результаты вычислений и примеры обработки ошибочных данных

### 1. Вывод данных и типов
```text
courseName: Бэкенд-разработка на языке Go (string)
name: Роман (string)
age: 20 (int)
average: 4.75 (float64)
active: true (bool)
```

### 2. Калькулятор
- `a = 5, b = 2, op = "/"`: `Результат: 2.5`
- `a = 5, b = 0, op = "/"`: `Ошибка: деление на ноль`
- `a = 5, b = 0, op = "%"`: `Ошибка: деление на ноль`
- `a = 5, b = 2, op = "?"`: `Ошибка: неизвестная операция "?"`

### 3. Последовательность и циклы
- `n = 5`:
  ```text
  Сумма чисел от 1 до 5: 15
  Количество чётных чисел: 2
  Первые чётные числа: 2 4
  ```
- `n = 10`:
  ```text
  Сумма чисел от 1 до 10: 55
  Количество чётных чисел: 5
  Первые чётные числа: 2 4 6
  ```
- `n = 0`: `Ошибка: число n = 0 находится вне диапазона от 1 до 100` (расчёт пропущен)
- `n = 101`: `Ошибка: число n = 101 находится вне диапазона от 1 до 100` (расчёт пропущен)
