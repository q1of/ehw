## Результаты работы функций

### 1. Stats
- Срез `[5 4 3 5 4 2 5]`: `min = 2, max = 5, average = 4, ok = true`
- Пустой срез `[]int{}`: `min = 0, max = 0, average = 0, ok = false`

### 2. GradeCounts
Количество оценок для `[5 4 3 5 4 2 5]`:
```text
2: 1
3: 1
4: 2
5: 3
```

Операции с map:
```text
До удаления: значение = 25, ok = true
После удаления: значение = 0, ok = false
```

### 3. WordCounts
Подсчёт слов для `"Go go язык Go язык"`:
```text
go: 3; язык: 2
```

Длина строки `"Привет"`:
- `len("Привет") = 12` (байты)
- `len([]rune("Привет")) = 6` (руны)
